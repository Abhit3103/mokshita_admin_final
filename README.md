# mokshita_admin_final

Production-ready Admin Portal for **Mokshita Handicrafts** built with React, Vite, Recharts, and Lucide Icons, adhering to the warm artisan design language of the Mokshita storefront.

## Features
- **Executive Dashboard**: Live revenue, order counts, active customer metrics, and interactive sales trend graphs.
- **Order Management**: Comprehensive order filtering, status fulfillment (Received, Shipped, Delivered, Cancelled), and courier tracking updater.
- **Product Catalog**: Full CRUD for handcrafted items, category assignments, stock health monitoring, and image upload.
- **Customer Directory**: Customer profiles, purchase histories, and lifetime spend metrics.
- **Customer Queries**: Contact inquiries and custom order requests directly from the main storefront.
- **Payment Operations**: Razorpay live gateway transaction tracking, signature verification, and manual confirmation for COD/pending orders.
- **Stock & Inventory**: Real-time stock health monitors with quick stock adjustment modals.
- **Analytics**: Business intelligence breakdown (AOV, revenue over time, top products, payment splits).
- **Settings**: Storefront metadata, shipping business rules viewer, and database infrastructure status.

## Tech Stack
- **Frontend**: React 18, React Router 6, Vite, Vanilla CSS Design System, Recharts, Lucide Icons, Axios
- **Backend API**: Node.js, Express, Supabase PostgreSQL, Supabase Auth
